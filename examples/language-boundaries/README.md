# Five-runtime boundary manifest

This directory contains a manifest example only. It names five required runtime boundaries but carries no fabricated runtime receipts.

Use `verifyLanguageBoundariesAgainstCurrentInputs()` in trusted promotion orchestration so TJSV first re-verifies the retained Contract IR against the current independently authored TypeSpec and JSON Schema inputs, then evaluates freshly produced runtime evidence. Do not treat this static manifest as proof that any runtime executed.
